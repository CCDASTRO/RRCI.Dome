2. Add Controller Type

enum ControllerType
{
    ALEKO_SINGLE_BUTTON = 1,
    OPEN_CLOSE = 2,
    OPEN_CLOSE_STOP = 3
};

ControllerType controllerType =
    ALEKO_SINGLE_BUTTON;

Default remains Aleko.

So existing installations behave identically.

4. Modify StartOpen()

Current:

PulseTriggerRelay();

Future:

switch(controllerType)
{
    case ALEKO_SINGLE_BUTTON:
        PulseOpenRelay();

    case OPEN_CLOSE:
        PulseOpenRelay();
        break;

    case OPEN_CLOSE_STOP:

        break;

Current:

Future:

{

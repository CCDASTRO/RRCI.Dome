RRCI Firmware V2 Multi-Controller Support

Firmware Version 2 extends the original RRCI roof controller firmware to support multiple motor controller architectures while maintaining 100% backward compatibility with existing Aleko-based installations.

Supported Controller Types

enum ControllerType
{
    ALEKO_SINGLE_BUTTON = 1,
    OPEN_CLOSE = 2,
    OPEN_CLOSE_STOP = 3
};
Mode Description
1 Aleko Single Button Controller
2 Dedicated Open / Close Controller
3 Dedicated Open / Close / Stop Controller

Relay Assignments

#define RELAY_OPEN      7
#define RELAY_CLOSE     6
#define RELAY_STOP      5
#define RELAY_SPARE     4

Controller Behavior

Mode 1 - Aleko Single Button

Command Relay Activated
Open Relay 7
Close Relay 7
Abort Relay 7

The motor controller internally handles the sequence: 

Open -> Stop -> Close -> Stop

Mode 2 - Open / Close Controller

Command Relay Activated
Open Relay 7
Close Relay 6
Abort No Action

Mode 3 - Open / Close / Stop Controller

Command Relay Activated
Open Relay 7
Close Relay 6
Abort Relay 5

Default Startup Mode

Firmware V2 defaults to Aleko compatibility mode: 

ControllerType controllerType =
    ALEKO_SINGLE_BUTTON;

This ensures all existing installations continue to operate exactly as they did under Firmware V1.

Runtime Mode Selection

Firmware V2 includes runtime mode switching commands: 

setmode:1#
setmode:2#
setmode:3#
Command Result
setmode:1# Select Aleko Single Button Mode
setmode:2# Select Open / Close Mode
setmode:3# Select Open / Close / Stop Mode

These commands immediately change controller behavior without requiring firmware recompilation.

Method 1 - Manual Firmware Configuration

Advanced users may select the controller type directly within the firmware source code. 

ControllerType controllerType =
    ALEKO_SINGLE_BUTTON;

Change to: 

ControllerType controllerType =
    OPEN_CLOSE;

or: 

ControllerType controllerType =
    OPEN_CLOSE_STOP;

Then recompile and upload the firmware.

Method 2 - Serial Terminal Configuration

Connect using any serial terminal such as:

  • Arduino Serial Monitor
  • PuTTY
  • TeraTerm
  • RealTerm

Send: 

setmode:1#
setmode:2#
setmode:3#

The firmware immediately changes operating mode.

Important: Current implementation does not save mode selections to EEPROM. The controller returns to Aleko Single Button Mode after a reboot.

Method 3 - Future ASCOM Driver Integration

Future versions of the ASCOM driver may expose controller selection through the Setup Dialog. 

Controller Type

(*) Aleko Single Button
( ) Open / Close
( ) Open / Close / Stop

The driver would transmit: 

setmode:1#
setmode:2#
setmode:3#

during connection.

No firmware changes are required because support is already built into V2.

Future Enhancements

EEPROM Storage

Store selected controller type in EEPROM: 

EEPROM.write(0, controllerType);

Load at startup: 

controllerType =
    (ControllerType)EEPROM.read(0);

This allows mode selections to survive power cycles.

Status Reporting

Future firmware may include controller mode reporting: 

STATE:OPEN;SAFE;MODE:1;IDLE#

This provides additional diagnostic information to ASCOM clients.
